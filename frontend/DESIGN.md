# DESIGN.md — MetroViz 城市地铁客流研究台

本规范取代原纸墨朱印与全屏夜墨 Hero 契约。业务需求、字段语义与验收见 `../docs/prd/`，用户于 2026-10-13 明确要求适度 3D 与动画。

## 1. 业务层级

围绕查城、读趋势、选择对标、核对来源组织界面。全国概览、城市档案、对标分析、线网图集为主导航；数据说明与逐城收录状态作为辅助入口。图表前说明指标、期间、有效样本和采集日，不能将采集时间改写为统计时间。

首屏显示主要控件和至少五个城市条目。空间分布与列表并列，三维不占据全屏。不使用无 OD 依据的跨城流线；不展示“全国日总客流”或综合实力雷达。

## 2. 视觉语言

浅灰绿画布、白色内容面、深墨文字和蓝绿色操作强调。使用细边线和有限留白组织高密度资料，标签用文字表达；选中节点可用暖色区分，但不表示经营好坏。

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| canvas | #F4F6F5 | 页面画布 |
| surface | #FFFFFF | 内容面 |
| text-primary | #182A2F | 正文与数字 |
| text-secondary | #53676D | 标签与辅助信息 |
| border | #D9E2E2 | 边线 |
| action | #146A73 | 按钮、当前导航、选中态 |
| selection | #E7F2F1 | 选中背景 |
| pending | #8A5900 | 来源待核验 |

`src/styles/research.css` 定义研究台语义变量与布局。`tokens.css` 继续为旧组件提供兼容类名，原 vermilion 系列在新版本映射为蓝绿色，不再代表朱红。

使用系统无衬线字体，数字启用 tabular-nums。桌面主要标题 30px，移动 24px；文字和控件根据密度调整，关键数值保持显著层级。需要横向滚动的原值表只在自身容器中滚动，页面不溢出。表格容器保持定位上下文，避免屏幕阅读器专用标签向页面外扩张。

## 3. 三维与动画

二维为默认视图，三维由用户显式启用并动态加载 echarts-gl。使用轻微挤出、柔和灯光和固定高度节点。节点面积表示当前指标，地形高度不表示业务值。可选城、聚焦、复位和拖动，默认不自动旋转，无循环粒子或飞线。

交互反馈 120–180ms，内容进入 220ms，图表更新 320ms，显式相机聚焦 420ms。数字直接显示最终值，不滚动计数。系统 prefers-reduced-motion 与站内减少动态效果设置任一生效即停止动画，仍保留数据与静态三维。

WebGL 不可用或上下文丢失回退二维；底图失败保留搜索和列表。移动端默认收起地图，用户可展开。图表具备列表或原值表等价访问路径。

## 4. 数据与组件纪律

所有研究页面使用 `lib/research.ts` 的观察值适配器，不读取合并层的零值兜底来判断资料存在。日快照与年度可用性独立计算。年份结束不代表完整统计期间已核验；严格比较同时检查期间、计数规则、系统范围与核验状态。

`WorkbenchUI` 复用控件、上下文、引用、表格与对比篮。对比篮最多五城，分享链接携带选择；仅一城时不自动补充示例。图表颜色按城市 ID 稳定映射，并辅以城市名称。资料完整度不混入业务指标。

城市图件查看器保留缩放与全屏，规划图必须保持类型提示。全屏支持 Escape、焦点约束与焦点返回。不得在业务界面中突出文件路径或构建框架。

## 5. 验证

运行 typecheck、lint、test:unit、build、check:static 与 test:ui。`scripts/acceptance-workbench.cjs` 映射 PRD 的 P0 验收并覆盖 320px、375px、桌面、减弱动效、故障降级和数据缺失。远端页面验证使用 test:pages；未发布前不宣称线上已经更新。
