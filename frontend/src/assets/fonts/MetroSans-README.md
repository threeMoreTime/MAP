# Metro Sans UI subset

Source: Google Fonts Noto Sans SC, https://github.com/google/fonts/tree/main/ofl/notosanssc (retrieved 2026-10-14). SIL Open Font License 1.1: `NotoSansSC-OFL.txt`.

`metro-sans-subset.woff2` is a WOFF2 subset of `NotoSansSC[wght].ttf`, retaining variable weights and glyphs appearing in frontend TypeScript sources and current JSON data, plus basic Latin. The CSS alias Metro Sans distinguishes this UI subset. Unsupported user-entered glyphs use system fallback.

Regenerate with fontTools subset when adding UI text; review font coverage and retain the license.
