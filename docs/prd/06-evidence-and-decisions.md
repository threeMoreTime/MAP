## 3 产品判断与证据边界

| 决策 | 依据 | 仍需验证 |
| --- | --- | --- |
| 以研究和资料查询为主 | 城市聚合与年度数据已具备 | 主要用户构成和访问目的 |
| 移除分析首页的装饰飞线 | 飞线没有对应跨城流向数据 | 展示用途是否需独立模式 |
| 按指标区分可用性 | 11 城日快照缺失但年度有值 | 是否存在其他指标异常 |
| 移除综合强弱雷达文案 | 多量纲、规模相关指标不等于运营质量 | 是否有明确研究模型支持其他综合评价 |
| 核验后再做严格对标 | 缺少统计期间和范围元数据 | 各源数据真实定义及可核验程度 |

用户人群、设计方向、阶段工时和成功目标为方案建议。文中源数据示例是仓库存量值，未用外部资料纠正或补充；不能作为当前实际运营结论。
