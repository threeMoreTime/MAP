# MetroViz 页面与交互规格

## 1 全局交互

全站共用指标字典、数据格式化、期间上下文和对比篮。金额类或经营评分不出现在当前产品。数字显示由字段单位驱动，不能根据标题临时拼接。

URL 保留浏览状态。拟采用 `metric=annual`、`year=2025`、`q=hangzhou`、`city=hangzhou`、`mode=reference` 等查询项；快照使用 `metric=daily_snapshot` 并删除年份参数；对标继续使用 `cities=beijing,shanghai`。年份非法时回到有记录的最近已结束年份并提示，不静默展示其他年份。

页面返回保留筛选及滚动位置。城市选择使用稳定 city ID，不用显示名称作为唯一键。对比篮使用 URL 加会话内状态，刷新以 URL 为准；仅有一个城市时保留它并提示再选一个，不自动填入陌生城市。超过五城时保留前五个有效且去重的 ID，并显示限制提示。

## 2 全国概览

P-01 对应 FR-01、02、03、08、09、11。

首屏顺序为主导航、页面标题、紧凑数据上下文、指标与期间控件、地图和城市列表。1440×900 桌面首屏应看到主要筛选及至少五个城市条目；不设置全屏宣传区。数据质量汇总压缩为一行，不将九个收录数与业务指标等权并排。

| 区域 | 内容 | 行为 |
| --- | --- | --- |
| 页面标题 | 全国客流概览 | 同时说明当前为资料浏览或严格比较 |
| 上下文条 | 指标、期间、有效记录数、采集日 | 点来源状态打开指标说明 |
| 控件区 | 搜索城市、指标、年份、可比模式 | 变更同时更新地图、列表和有效样本数 |
| 空间分布 | 可切换二维 / 三维的城市分布地图 | 二维气泡面积映射数值；三维节点高度固定、面积映射数值；缺失城市用小型空心或灰色标记 |
| 城市列表 | 城市、当前值、数据状态、加入对标 | 默认按名称；可切换源值排序 |
| 城市摘要 | 选中城市、年度小趋势、进入档案 | 点击地图或列表同步选中；摘要不遮住筛选 |

地图回答“城市分布在哪里”，列表承担精确读取。地图不画跨城飞线、不以行政区面积代表地铁规模。地图加载失败时保留列表和搜索。移动端默认列表，地图通过显式切换进入，不要求用户操作小气泡。

默认视图采用最近已结束年份的年度资料；当前仓库对应 2025 年。年份结束不等于统计口径已经核验，因此默认为资料浏览，持续显示“源数据口径待核验”。严格比较只显示通过可比性检查的记录；若没有合格记录，呈现原因和返回资料浏览按钮。

源值排序仅用于浏览，未知口径不显示“全国第几名”。所有合计必须叫“所选样本合计”，具有相同期间和一致口径后才允许计算；当前未核验快照不展示“全国日总客流”。

## 3 城市档案目录

P-02 对应 FR-02、04、10。桌面默认紧凑列表，可切换等高卡片。去除高低不一的旅游式封面瀑布流。搜索支持中文、全拼和现有城市 ID；输入无结果显示查询词和清空按钮。

条目含城市名、当前指标值、年度趋势是否有记录、线路图和规划图状态。运营里程等快照信息必须单独标注期间未核验，不能放在年度表头下假装同年数据。

筛选拆为当前指标可用性和资料类型。杭州在年度指标下应属于“有年度数据”，在日快照下属于“日快照缺失”。福州等仅有图件的城市仍可进入档案和图集。增加对标按钮独立于打开条目，阻止点击事件误触详情。

## 4 城市档案详情

P-03 对应 FR-05、07、08、09。头部显示城市名、返回路径和加入对标主操作。主体分为客流分析与线网资料两页签，默认客流分析；只有图件的城市默认线网资料，并保留另一页签的明确空态。

客流分析首层呈现当前年度日均客流、数据期间、来源核验状态；第二层呈现年度趋势与原始表。运营里程、线路数和站点数放在单独的运营资料区，附各自统计时点。未取得同年里程时不计算该年度客流强度。

趋势默认展示已有年份至最近已结束年，不平滑补齐缺失年份。2026 年记录归入“未确认完整期间”并在详情表单独显示；用户明确启用后可在趋势中以空心点与虚线区分，不能连成正常全年走势。

来源面板显示发布机构或网站、原始链接、统计期间、采集日、核验状态。图件显示图名、线路图或规划图、版本日期及授权信息；未知写“图件版本未提供”。本地文件路径仅供维护诊断，不占据业务页面。

复制引用包含城市、指标、数值、单位、统计期间、采集日期、来源和口径状态。地图滚轮缩放、拖拽及全屏继续复用现有查看器，帮助移到工具栏旁，避免常驻大块使用说明。

## 5 对标分析

P-04 对应 FR-06、09、10。页面任务是理解城市差异，不产出综合实力评分。最多五城，默认以用户选择为准；无选择时提供“选择城市开始比较”空态和可点击示例组合，示例不会自动替换用户选择。

控件为城市选择、指标、期间、资料浏览或严格比较。上方显示可比性结果，下方使用横向条形图与原值表；趋势在同一页中展示。图表直接标记单位、城市名称和数值，颜色按城市 ID 稳定映射，不随排序改变。

严格比较检查指标定义、统计期间、系统范围、计数规则、单位与核验状态。存在不一致时，显示不匹配城市及原因，用户可移除这些城市或转资料浏览；不能直接给出相对百分比。一个城市缺值时保留其列并写明原因，不从明细表静默删除。

仅 P1 且元数据满足条件时，提供相对基准差值、共同基期指数和同比。基准值必须大于零；年份须共同有效且为完整同期。客流强度是单位里程客流水平，不等于盈利、运力利用率、拥挤度或经营效率。

移动端保留全部选择，采用城市卡片和指标行逐组展示。不可因屏幕变窄静默删除第三至第五个城市。必要的明细表可在自身容器内横向滚动，页面整体不溢出。

## 6 线网图集与数据说明

P-05 图集支持城市搜索、线路图或规划图筛选、可用资源列表和查看器。规划资料始终使用文字标签。资料缺失时显示缺什么及去哪里查看来源，不使用空白图片位或持续加载。

P-06 数据说明包含指标字典、来源、采集与生成日期、系统覆盖范围和维护记录。数据质量子页按指标列出可用、缺失、期间未知、口径待核验四类状态，图片和封面归入资料收录，不参与指标可信度评级。

## 7 状态规则

| 状态 | 页面呈现 | 恢复动作 |
| --- | --- | --- |
| 首次加载 | 与结果布局一致的骨架及文字 | 加载成功后保留控件位置 |
| 搜索无结果 | 未找到匹配城市 | 清空查询 |
| 指标缺失 | 显示破折号与缺失原因 | 切换可用指标或查看图件 |
| 可比性不满足 | 列出不满足的条件 | 移除城市或转资料浏览 |
| 数据请求失败 | 数据加载失败及重试按钮 | 重试同一请求，不展示示例冒充真实结果 |
| 地图失败 | 空间视图不可用，列表仍可操作 | 重试地图 |
| 复制失败 | 选中可手动复制的完整引用或链接 | 显示手动复制区域 |
| 数据较旧 | 最近采集日和距今天数 | 查看来源；不宣称统计值已经失效 |

弹层可用 Esc 关闭，焦点返回触发按钮；对话框内焦点不逃逸。所有关键状态同时具备文字表达，不只依赖颜色、透明度或悬停。

## 8 三维与动画交互（FR-15）

地图默认二维，用户可显式切换三维；三维按需加载，不延迟列表可用。地理底图使用低高度挤出、柔和光照，选中城市突出显示并允许显式聚焦和复位。节点大小表示当前指标值，地形高度不编码任何业务指标。无 OD 数据不显示跨城流线。移动端默认列表，空间视图按需展开。

控件反馈 120–180ms，页面内容显现 220ms，图表切换与聚焦 300–450ms。列表数字不滚动计数，不自动旋转镜头，不循环闪烁。动画可随时被后续操作打断。全局提供“减少动态效果”开关，并始终尊重 prefers-reduced-motion；此时取消过渡、禁用相机动画，保留静态三维。离屏或后台不运行循环动画。

WebGL 不可用或上下文丢失时回退二维并给出文字说明；地理资源也失败时保留城市列表和重试入口。三维画布不承担唯一的信息访问方式，键盘用户通过列表获得等价操作。
