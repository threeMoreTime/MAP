# MetroViz 数据指标与可信度规则

## 1 数据事实与迁移原则

当前数据是公开来源的采集快照。存在月度更新工作流不代表当前数据已按月更新成功，也不代表数据实时。此次核对基线共 50 城资源、34 城统计记录、23 城正数日快照、34 城年度序列、48 城线路图、41 城规划图。

迁移保持原始城市 JSON 和历史快照不变。在数据适配层新增标准字段及元数据，缺失或未知使用 null 和状态字段表达。任何推导值必须可追溯到输入，不能为了视觉完整编造记录。

## 2 指标字典

| 指标编号 | 显示名称及来源字段 | 单位和展示规则 | 可用条件 |
| --- | --- | --- | --- |
| M-01 | 日客流快照 daily_ridership_wan | 万人次，保留两位小数 | 值大于零；统计日未知时说明 |
| M-02 | 年度日均客流 yearly_avg_ridership | 万人次每日，保留两位小数 | 指定年份有有限数值；期间完整性另判 |
| M-03 | 运营里程 operating_mileage_km | 公里，最多一位小数 | 值大于零且保留其统计时点 |
| M-04 | 运营线路 operating_lines | 条，整数 | 缺失与真实零必须由来源区分 |
| M-05 | 运营站点 operating_stations | 座，整数 | 需核验换乘站是否重复计数 |
| M-06 | 客流强度 ridership_intensity | 万人次每公里每日，三位小数 | 日客流与里程时点和范围匹配 |
| M-07 | 历史单日峰值 peak_ridership_wan | 万人次，两位小数，附发生日 | 正数且有来源；无日期标记未知 |
| M-08 | 在建线路 lines_under_construction | 条，整数 | 真实零可有效；不能沿用全局大于零规则 |

M-01 的爬虫来源为页面中的 `flow_last`，现有 JSON 未保留它的统计日期；现有文档又将其解释为日均。核验前统一称日客流快照，不直接称今日、昨日或年度日均客流。

M-02 依据现有字段语义称年度日均，但该命名不自动证明各城系统范围相同。当前文件在 2026 年 5 月采集并含 2026 年值，不能将此值视为全年完成值，也不能假定其截止日恰好是采集日。

M-06 当前直接抓取源站 `flow_ratio`。原始比率可作为待核验来源值保留；重新计算时，分子必须为匹配期间的日均客流、分母为匹配范围的里程。不能将 2025 年客流除以没有年份的最新里程并称 2025 年强度。

## 3 拟新增数据契约

建议新增 `data/latest/metric_metadata.json` 与 schema，按 city、metric、periodKey 索引。保留现有四份数据文件兼容旧版消费者。前端适配器输出 MetricObservation，不要求立刻建设后端。

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| cityId、metricId | string | 使用稳定 ID |
| value、unit | number 或 null、string | 数值与显示字符串分离 |
| periodType | enum | daily、annual、year_to_date、snapshot、unknown |
| periodStart、periodEnd、asOfDate | ISO 日期或 null | 未知不得使用采集日补齐 |
| periodCompleteness | enum | complete、partial、unknown |
| sourceUrl、sourceName | string 或 null | 原始来源及名称 |
| collectedAt、generatedAt | ISO 时间或 null | 分别表示采集与数据包生成 |
| systemScope、countingMethod | string 或 null | 地铁或轨道范围及计数方式 |
| verificationStatus | enum | pending、verified、rejected |
| verifiedBy、verifiedAt | string 或 null | 仅记录真实核验者与时间 |
| availability、missingReason | enum、string 或 null | available、missing、invalid |
| provenance | enum | source、derived；衍生值另存输入引用 |

来源 URL 可从已确认的爬虫模板恢复，但必须标记来源于抓取配置；不能据此宣称原页面已重新访问或发布机构已经认证。元数据默认 pending，历史数据批量回填时不设 verified。

## 4 可比性与计算规则

R-01 资料浏览允许显示来源值、原始趋势和缺失情况，常驻口径状态。严格比较必须满足相同 metricId、单位、统计起止、完整性、系统范围及计数方式，且记录通过核验。未知不等于相同。

R-02 原始快照的 daily_ridership_wan 小于等于零按本项目既有来源约定视为缺失，不显示 0 客流。该规则仅适用于明确约定的字段，不应套用到在建线路等允许真实零的字段。

R-03 年度序列的 years 和 values 必须等长，同一年只允许一个值；非数、重复年份和不合理负值标记 invalid。缺失年份输出 null 并断线，不能补零、外推或平滑补齐。

R-04 切换指标或期间后重新计算 N。上屏文案为“34 城有该年度记录”或“23 城有日快照值”，不写“50 城都有数据”。严格样本 N 与资料浏览 N 分别计算。

R-05 同比仅用于两个相邻、完整且口径一致的年度，计算为本年值除以上年值再减一。前期值小于等于零或任一状态未知时不计算。正负变化是描述性信息，不默认代表好坏。

R-06 共同基期指数以用户选择的共同有效完整年份为 100，指数为当期值除以基期值再乘 100。不能为每城选择不同基年后画在同一可比图中。

R-07 样本合计只能汇总同期、同口径且不重复计数的数据。页面、导出和引用均附样本范围与 N；未覆盖总体时不用全国总量。客流强度的总体值如需计算，应以客流合计除以匹配里程合计，不能简单平均各城比率。

R-08 排名基于当前严格样本；并列采用竞赛名次 1、2、2、4，同时展示样本数。资料浏览按数值排序只显示序号或不显示序号，不称官方或全国名次。

R-09 来源收录完整不等于事实正确、口径一致或数据新鲜。取消以图片、封面加权得出的综合分在业务指标区的展示；资料收录页可保留旧分数作为维护信息并解释算法。

## 5 日期显示规则

统计期间回答“数值描述哪一天或哪一段时间”；采集日回答“什么时候取得资料”；生成日回答“什么时候生成索引”；图件版本日回答“图反映何时的线网”。四者独立显示。

当前基线采集日为 2026-05-08，生成日为 2026-08-17。页面首层显示采集日，详情面板显示生成日。旧文案“数据截至采集日”改为“最近采集”，除非确实拿到统计截至日期。

保留已有超过 90 天提示规则，但文案称“采集距今超过 90 天”。年度历史事实不因采集较旧自动变为无效；新鲜度不能替代来源核验。日级日期按来源时区保存，时间戳保留偏移；界面距今天数统一用 Asia/Shanghai 日历日计算。
