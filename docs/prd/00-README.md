# MetroViz 业务视觉重构文档导航

本套规范将 MetroViz 定位为面向城市轨道交通研究与资料查询的客流研究台。核心工作流为查找城市、阅读历史变化、选择可比城市、引用结果。首页、城市档案和对标分析围绕这些任务组织。

版本为 1.1，日期为 2026 年 10 月 13 日，状态为产品与研发实施版。方案以仓库提交 `852dbdd9b59a3d48b77325e34c2cac5b30ec7533` 为基线。目标用户、工作量与效果目标属于待验证的产品假设；数据覆盖数和实现现状已根据该提交核对。

## 文档优先级

指标和可比性以 03 为准；页面行为以 02 为准；样式以 04 为准；范围以 01 为准；发布验收以 05 为准。原型与文字冲突时先按文字执行，并记录差异。原型省略地理底图、完整图集、导出和正式路由，不代表删除这些需求。

## 维护方式

需求使用 FR 编号，验收使用 AC 编号，实施任务使用 DEV 编号。变更须同时更新范围、相关页面规则、验收用例和决策记录。旧需求标注被替代版本，避免仅修改原型。本目录随功能分支纳入现有仓库，实施结果见 07-implementation-report.md。

业务定位与配色可独立调整；缺失值不等于零、采集日不等于统计日、未知口径不得自动参与严格比较，是上线前必须满足的数据规则。
