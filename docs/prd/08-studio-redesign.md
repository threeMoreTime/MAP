# MetroViz Studio v2.0 · 地图研究工作台重设计

状态：实现与验收中。2026-10-14，根据用户对首版视觉的不满意重新设计。此版本覆盖 04 章中旧版颜色与首页空间布局；数据契约、来源约束、严格比较规则继续有效。

## 1. 问题与目标

首版使用宣传式标题、多行说明和均匀面板，地图在业务页面中的优先级偏低；查找城市后，摘要位于地图下方，阅读需要反复移动。浅灰绿地图与页面缺少层次，3D 场景的空间深度不足。

v2 以实际任务为中心：选择研究指标和年份 → 观察城市分布 → 在右侧读取城市指标与历史轨迹 → 进入档案或加入对标。首页是一张可操作的研究工作台。

## 3. 信息架构

- 桌面：固定侧栏承载全国概览、城市档案、对标分析、线网图集；顶部面包屑显示位置、历史资料属性和动效设置。
- 首屏：简洁页标题 → 四项资料规模计数 → 指标/年份/查城控件 → 研究上下文 → 地图与当前关注城市并列。
- 当前关注面板：城市切换、源数据值、单位、统计期间、核验状态、近 7 个已结束年份的客流趋势、图件收录、档案和对标入口、来源详情。
- 城市索引：完整清单置于主视图下方，局部滚动；点城市与上方地图、关注面板同步，继续支持源值排序和中文/拼音查询。
- 移动：底部四项主导航；地图默认收起，显式展开；关注城市面板和城市列表始终可访问。

“首屏至少五行列表”由“桌面首屏呈现主要地图和关注城市数值”替代。完整城市索引必须在同一页面可达，不能删除或仅显示推荐城市。

## 4. 视觉方向

采用深蓝侧栏与空间画布、浅灰页面、白色数据面板。蓝色表示操作，薄荷色标记地图选中城市，暖色只用于资料状态。统一无衬线字体、等宽数字、线性 SVG 图标。随站点提供 OFL 授权的 Noto Sans SC 字形子集（可变字重），保障缺少系统中文字体的环境也能正确显示。移除首页宣传大标题和字体混搭。

地图边界与节点分离：暗蓝省区、细描边、浅蓝数据节点、薄荷色选中节点。背景网格仅提供空间阅读层次，不标注不存在的地理坐标。面板轻阴影、8–11px 圆角，卡片 hover 仅轻微上移。

## 5. 交互及三维

1. 保持默认二维和按需加载 3D，避免未操作时下载 GL 包。
2. 二维支持拖动/缩放，三维支持视角调整；工具提供放大、缩小、聚焦城市、复位、显示/隐藏城市名。
3. 切换维度不改变指标、年份、所选城市或对标篮。颜色和指标语义保持一致。
4. 三维使用等高挤出地理面和固定高度节点。节点大小表示源值，地理高度不是业务数值；右侧数字用于精确阅读。
5. 默认不自动旋转，不播放无限粒子、伪客流动画；所有动效服从系统和手动 reduced-motion。
6. 无 WebGL、上下文丢失、底图失败均沿用已有恢复逻辑；键盘用户可用关注城市下拉框和城市表格完成同等选择。

## 6. 数据纪律

四项顶部计数来自实际城市资源、年度序列、有效日快照和线网图件数量。它们属于资料覆盖，不代表全国总客流或实时运营状态。

关注面板的趋势只使用真实年度原值，按年份排列、最多展示最近 7 年，排除晚于所选年份及采集年尚未结束的期间。缺失值不补齐；没有有效序列就显示空态。每日快照缺失时，年度历史仍可展示。

日期、未知计数口径、源引用、严格比较阻止规则、对标上限、分享链接继续沿用 v1.1 的数据契约。
